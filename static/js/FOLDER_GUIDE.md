# static/js/ — Browser JavaScript

`app.js` browser me chalne wala JavaScript hai. **User button click kare, camera khole, image preview dekhe, chatbot message bheje ya UI language/layout change ho — uska interactive behavior yahan hota hai.**

Main areas:
- Chatbot UI + Gemini response formatting
- Camera capture and image preview
- Plant/soil analysis UI helpers
- Navigation/menu interactions
- Weather/location browser actions
- Safe HTML escaping
- Multilingual frontend text helpers

Backend AI logic `app.py` me hai; browser JS sirf request bhejta/response dikhata hai.
